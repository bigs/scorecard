# Scorecard TODOs

Running list of ideas and outstanding work, kept in the repo so context survives between sessions.

## Done
- [x] **Two display modes — floating panel vs. menu-bar compact.**
      Shipped. `DisplayMode.{floating, compact}` persisted in
      `UserDefaults`. Compact mode renders as a pure `NSMenu` (no popover)
      with the top 10 as full-opacity, non-interactive custom-view rows,
      followed by a Tournament submenu, Switch to Floating, Refresh, Quit.
      Status item shows tournament name beside the scorecard icon in compact.
- [x] **App icon + menu bar icon.** Custom scorecard-folded-in-half
      silhouette. AppIcon is a dark-green silhouette on a cream squircle.
      Menu bar uses the same shape as a template image. Both generated by
      `Scripts/generate_icons.swift` from a single SwiftUI `Shape`; re-run
      that script to regenerate every size in one go.

## Backlog
- [ ] **Resize-edge cursor.** When the cursor hovers over the panel's
      edges/corners, swap to the matching resize affordance (NS/EW/diag)
      so the resize zones are visible. Tried so far:
      (a) `NSTrackingArea` + `cursorUpdate` on an overlay `NSView` — callback
          never fires, SwiftUI's hosting view swallows the tracking.
      (b) Legacy `resetCursorRects` cursor rects on an overlay — same story,
          the system never asks our overlay for rects.
      (c) `FloatingPanel.sendEvent(_:)` override — `.mouseMoved` events
          don't reach a non-activating panel even with
          `acceptsMouseMovedEvents = true`.
      (d) `NSEvent.addLocalMonitorForEvents(matching: .mouseMoved)` with
          `NSCursor.set()` — fires, but SwiftUI's tracking races and resets
          the cursor to default before it's visible.
      (e) SwiftUI overlay strips with `.pointerStyle(.frameResize(position:))`
          — the right idea structurally but the strips weren't rendering
          where expected; needs another pass. Likely answer is (e) once
          the strip layout is correct.
- [ ] **Per-hole scorecard data.** The expanded row currently shows round
      totals only. Hit ESPN's player-event endpoint to render a real
      front-nine/back-nine grid with strokes per hole and color coding for
      eagle/birdie/par/bogey.
- [ ] **Favorites flow polish.** Starring works (right-click menu in
      floating mode) but there is no UI hint that you can do it; needs a
      discoverable affordance and maybe a quick keyboard shortcut. Verify
      the starred-section pinning renders correctly once a tournament is
      live. Consider right-click on a compact-menu row to star/unstar.
- [ ] **Compact menu auto-refresh while open.** Menu items are a snapshot
      at open time. If a round is live and the user holds the menu open,
      scores go stale. Wire `NSMenuDelegate.menuNeedsUpdate(_:)` or rebuild
      items in response to `AppState` changes while the menu is open.
- [ ] **Compact menu status line.** Floating mode shows round status
      ("Round 2 - In Progress") in the footer; compact mode doesn't surface
      it anywhere. Consider a small disabled row above the leaderboard, or
      an italic line under the section header.
- [ ] **Cut line readout.** ESPN reports the projected/active cut score on
      `competitions[].notes`; the parser exists but is untested against real
      live data — confirm + surface it visually (a thin row in the list at
      the cut position, or a footer chip).
- [ ] **Better tournament status detail.** When ESPN omits `detail`
      /`shortDetail` (e.g. pre-tournament), fall back to `description` so the
      footer shows something useful ("Scheduled", "Final").
- [ ] **Player headshots.** ESPN provides `headshot.href` per athlete;
      optionally render a small circular image in the row for starred /
      expanded players.
- [ ] **App icon.** Currently empty `AppIcon.appiconset`. Design a flag-
      checker-on-glass icon for the Dock (when active) and the menu bar.
- [ ] **Refresh button affordance.** Visible spinner on the status footer
      while polling, plus a click-to-refresh control somewhere obvious.
